# Subagent Bridge 0.2.0 — macOS preview

Your favorite agents. Now your subagents.

The first public desktop preview lets you write delegation rules as sentences,
select models and thinking per worker, and connect Codex, Pi, OpenCode, and
DeepSeek Harness through versioned integrations. Each worker uses its own
harness and provider settings, with the parent session's project folder.

## Download and install

- Download **Subagent-Bridge_0.2.0_arm64.dmg** below. Apple Silicon only; targets
  macOS 12+. Node.js 22.13+ and your coding agents must be installed separately.
- Drag the app to Applications before applying rules. See the included Read Me
  or the [installation guide](https://github.com/Tarachand-Gupta/subagent-bridge/blob/v0.2.0/docs/install-macos.md).
- This is an **ad-hoc signed, unnotarized preview**. It has no Developer ID
  signature. macOS may block first launch; the installation guide explains the
  per-app Open Anyway flow. A signed, notarized release is still outstanding.
- Codex and Pi workers need the separately installed, pinned ACP adapters listed
  in the guide. Model usage is billed or limited by the worker's own provider.
- **SHA256SUMS** accompanies the installer. Verify it in the download directory
  with `shasum -a 256 -c SHA256SUMS`.

## Included

- Local rule editor, multi-model choices, per-model thinking, custom tasks, and
  optional prompt previews.
- Separate Save Rules and Apply actions, preserving existing live rules until
  they are applied.
- Background delegation and follow-up messages in the same live worker
  conversation for supported integrations.
- Configuration MCP with read, preview, save, agent, and model discovery tools.
- Structured errors, bounded execution, and version-specific harness handlers.
- MIT-licensed application source. Existing Harness Bridge rules and integration
  identifiers remain compatible.

## Current limits

This is a preview, not a claim that every harness version, model, or provider has
been verified. Claude Code is deferred. Windows, Linux, and Intel Mac installers
are not included. Native acceptance covers the maintainer's Apple Silicon Mac;
the minimum macOS target is not an all-version acceptance result.

Codex completions arrive during active turns or on the next turn; idle desktop
chats are not woken. Busy follow-up messages queue for the worker's next turn.
Worker conversation context does not survive its service shutting down. Shared
project folders are not isolated worktrees, and concurrent edits are not merged
automatically. The full parent chat is not automatically copied to the worker.

See [compatibility and integration records](https://github.com/Tarachand-Gupta/subagent-bridge#parent-integrations)
for tested versions and the limits of each integration.

## Validation for this release

- Regression suite: 100 passed, one Windows-only test skipped on macOS.
- macOS app and DMG rebuilt from the tagged source; bundle integrity verified.
- Packaged backend checked with an isolated home and no saved Bridge rules.

The build is not notarized, and clean-machine Gatekeeper acceptance across macOS
versions has not been established.
