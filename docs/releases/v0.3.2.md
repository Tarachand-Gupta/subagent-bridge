# Subagent Bridge 0.3.2 — signed macOS installer

The macOS app is now signed with Tarachand Gupta’s **Developer ID Application**
certificate and notarized by Apple. The app and DMG carry stapled notarization
tickets. Download, drag to Applications, and open normally; the earlier preview’s
Open Anyway workaround is no longer expected.

- Release packaging signs the app’s native dependencies before sealing the app.
- Hardened runtime and secure timestamps are enabled. No runtime exceptions were added.
- Future releases use the same signing procedure; signing failures stop packaging.
- The README is shorter and includes an application screenshot, with detailed guides under `docs/`.

## Downloads

- **Subagent-Bridge_0.3.2_arm64.dmg** — Apple Silicon, macOS 12+.
- **subagent-bridge-local-0.3.2.tgz** — CLI package; install with `npm install --global ./subagent-bridge-local-0.3.2.tgz`.
- **SHA256SUMS** — checksums generated after notarization and stapling.

Node.js 22.13+ and your configured coding agents are still required. Intel Mac,
Windows, and Linux installers are not included. This release does not add agent
compatibility or change delegation behavior.

## Updating

Quit the previous app after its running work finishes, replace it in Applications,
and open the new copy. Keep `~/.harness-bridge` intact: rules, saved drafts, provider
configuration, and integration identifiers have not changed. If the app’s location
changes, Apply Rules from the new copy and reload the parent agents.

See the [installation guide](https://github.com/Tarachand-Gupta/subagent-bridge/blob/v0.3.2/docs/install-macos.md)
and [signing procedure](https://github.com/Tarachand-Gupta/subagent-bridge/blob/v0.3.2/docs/macos-signing.md).
