# Subagent Bridge 0.3.1 — configuration controls

Settings now gives you a compact place to view, open, export, and import your rule configuration.

- View the current editor rules and the rules agents are using, with a read-only JSON preview.
- Open the applied config file in your default editor, or export the current rules to a JSON file.
- Import validates the file and shows a preview before loading it into the editor. Save and Apply stays explicit.
- The desktop app and CLI continue sharing the same config and draft files. Existing rules, provider credentials, and agent integrations need no migration.

Exports contain rule configuration only. Task-name presets, display preferences, credentials, and MCP installations are separate.

## Downloads

- **Subagent-Bridge_0.3.1_arm64.dmg** — Apple Silicon, macOS 12+, Node.js 22.13+.
- **subagent-bridge-local-0.3.1.tgz** — standalone CLI package; install with `npm install --global ./subagent-bridge-local-0.3.1.tgz`. Not published to npm.
- **SHA256SUMS** — checksums for both packages.

This macOS preview is **ad-hoc signed, not Developer ID signed or notarized**. See the [Mac installation guide](https://github.com/Tarachand-Gupta/subagent-bridge/blob/v0.3.1/docs/install-macos.md) for first launch and worker adapters. Windows/Linux desktop and Intel macOS installers are not included.

Keep `~/.harness-bridge` intact. Install the app at a stable location; Apply Rules can update integration paths. Keep the previous runtime available until its running work finishes and the updated connection is verified.

The agent catalog and native parent coverage are unchanged from [0.3.0](https://github.com/Tarachand-Gupta/subagent-bridge/releases/tag/v0.3.0). This update does not claim new live-provider acceptance. See the [CLI guide](https://github.com/Tarachand-Gupta/subagent-bridge/blob/v0.3.1/docs/cli.md) and [configuration acceptance record](https://github.com/Tarachand-Gupta/subagent-bridge/blob/v0.3.1/docs/configuration-acceptance-2026-10-16.md).
